# 九组参考摄影主题（V7.20）

本轮目标是把用户给出的九组拼图落实为九个可选择的独立主题，保留已有风格与服饰。
主题数据统一放在 `backend/app/reference_styles.py`，由现有提示词、造型、服饰和导演流程读取，
不增加第二套图片服务或改变用户当前模型设置。用户参考图用于视觉拆解，不用于确定示例新人的身份。

## 交付和验证

1. 九套都必须通过现有风格接口和造型选项接口出现，且可以创建造型、样片、导演草稿和组照任务。
2. 样片和整组使用同一套服饰；服饰、头饰和花束在不同镜头中保持一致。
3. 欧法、白马、蓝调夜景、森系、街拍在 4 张及以上的小组中允许一张氛围照，其余仍以两人面部可见为主。
4. 每套实际制作一张代表样片和四张导演组照，用同一对示例新人核查服饰、布光、构图、动作与整组连贯性。
5. 审阅图先保存到 `data/style-review/v720/`；查看实际结果后再发布页面样片。
6. 图像生成使用应用当前服务和模型；失败不自动重发，不静默切换服务；保存实际提示词、镜头方案和原图。
7. 自动测试验证数据覆盖、服饰传递和业务链路，审美效果通过实际图片与参考图对照判断，不能用测试数量替代。

这是摄影主题与生成规则的实现规格，不承诺随机生成的每张照片与参考完全相同。
